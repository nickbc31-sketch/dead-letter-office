MARA VENN — SPRITE SET (cut from MARA_REF_Tran.png)
===================================================
51 PNG files, each 128 x 192 px, transparent background.
Each Mara is cut directly from the sheet (pixel-perfect, no redraw); the
near-white checkerboard background was keyed out and each figure's interior
filled so nothing shows through. Titles and numbers are excluded.
Each figure is bottom-anchored and horizontally centred on its 128x192 canvas.

READ ME - THINGS TO CHECK
-------------------------
1. TERMINAL & HACK PROPS: in these frames Mara interacts with a terminal kiosk
   (and a cable). The kiosk/cable physically overlap her and sit inside the
   frame, so they are INCLUDED in those sprites. If you want Mara on her own
   (kiosk/cable removed), say so and I'll re-cut figure-only versions.

2. EMP_ACTIVATION 06-08 ARE NOT MARA: 01-05 are Mara raising/firing the PDA.
   06 = EMP wave, 07 = drone, 08 = drone destroyed. They're part of the
   animation but aren't the character - delete them if you only want Mara.

3. ROW-3 HEIGHT: scan / terminal / hack figures are drawn slightly shorter in
   the source art than idle/walk, so they sit a little lower in the 192px frame.
   Tell me if you want every animation scaled to a uniform character height.
