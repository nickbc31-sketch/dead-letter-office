# How to Add a Platform Level

Platform levels are defined in `Data/Levels/level_chN.json`.

## Minimal level structure

```json
{
  "id": "level_ch2",
  "chapter": "ch2",
  "displayName": "LOCATION NAME — AREA NAME",
  "tileMapName": null,
  "backgroundLayers": [
    {
      "imageName": "bg_city_far",
      "zPosition": -30,
      "scrollFactor": 0.1,
      "yOffset": 0
    }
  ],
  "spawnPoint": [120, 60],
  "exits": [
    {"type": "level_end", "x": "2800", "y": "60", "nextSceneHint": "desk_ch3"}
  ],
  "interactables": [],
  "patrols": [],
  "pickups": [],
  "environmentalTextNodes": [],
  "ambientMusicTrack": "ambient_platform",
  "levelWidth": 3000,
  "levelHeight": 400
}
```

## Background layers

Layers are rendered back-to-front by `zPosition`. Typical setup:
- Far layer: `zPosition: -30`, `scrollFactor: 0.1` (barely moves)
- Mid layer: `zPosition: -20`, `scrollFactor: 0.4`
- Near layer: `zPosition: -10`, `scrollFactor: 0.7`

`imageName` should match a PNG filename in `Art/Backgrounds/` (without .png extension).
If the image isn't found, the engine procedurally generates a placeholder cityscape.

## Interactables

Supported types:
- `terminal` — Mara can interact to read text or trigger dialogue
- `door` — Requires a flag or a code to open
- `cartridge` — Pickup that sets a flag and shows text
- `text_sign` — Environmental text, no interaction required
- `ladder` — Climb point (visual only in this version)

```json
{
  "id": "terminal_01",
  "type": "terminal",
  "position": [340, 68],
  "requiredFlag": null,
  "setsFlag": "terminal01_read",
  "requiredCode": null,
  "displayText": null,
  "cartridgeData": "Text shown when player reads cartridge.",
  "linkedDialogueID": "dialogue_id"
}
```

## Patrol drones

```json
{
  "enemyType": "security_drone",
  "points": [[500, 130], [700, 130]],
  "speed": 60,
  "pauseDuration": 1.5
}
```

`points` is an array of [x, y] waypoints. The drone patrols between them.
`speed` is pixels per second. `pauseDuration` is seconds paused at each waypoint.

## Pickups

```json
{"id": "pickup_01", "x": "280", "y": "140", "setsFlag": "pickup01_collected"}
```

Pickups are data cartridges Mara can collect. They set a flag and play a sound.

## Level dimensions

`levelWidth` and `levelHeight` define the total scrollable area.
Platforms are procedurally generated by the engine based on hardcoded values in `PlatformScene.swift`.
For custom platforms: modify the `buildFloor` method to read from the level JSON.

## Tips

- Keep levels 5–8 minutes long (player moving at normal pace).
- Ensure there are clear paths that avoid drones (stealth is always possible).
- Use `environmentalTextNodes` to add atmosphere — cryptic signs, propaganda, warnings.
- The access code `4471` in Chapter 1 is derived from case `case_ch1_001` sender ID `VC-4471-M`.
  Link level puzzles to desk case content for narrative cohesion.
